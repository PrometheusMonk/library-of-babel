# 巴別圖書館｜Library of Babel

一個以 **Minecraft 遊戲內閱讀** 為核心的模組計畫。

> 在 Minecraft 裡，建立一座可以真正閱讀的圖書館。

---

## 網站上線

這份網站可以直接使用 **GitHub Pages**。

### 1. 建立 Repository

建議名稱：

`library-of-babel`

### 2. 上傳檔案

把本資料夾中的檔案全部上傳到 repository：

- `index.html`
- `style.css`
- `config.js`
- `script.js`
- `update.json`
- `README.md`

### 3. 修改 config.js

請把：

- `YOUR_USERNAME`
- `YOUR_NAME`

換成你的 GitHub 使用者名稱與收款頁名稱。

### 4. 開啟 GitHub Pages

進入：

`Settings → Pages`

選擇：

`Deploy from a branch`

然後：

`main / root`

按下 Save。

你的網站之後通常會是：

`https://你的帳號.github.io/library-of-babel/`

---

## 目標 Minecraft 版本

本計畫目前以：

- **Minecraft 1.12.2**
- **Minecraft Forge 1.12.2**

為主要開發環境。

發布 `.jar` 時，建議在檔名中標示 Minecraft 版本，例如：

`library-of-babel-1.12.2-0.1.0.jar`


## 發布模組

正式 `.jar` 建議透過 GitHub Releases 發布。

檔案命名建議：

`library-of-babel-0.1.0.jar`

版本格式：

- `v0.1.0`
- `v0.2.0`
- `v1.0.0`
